# mallang-privacy

말랑수비대(Mallang Defenders) 개인정보처리방침 공개 페이지.

- 공개 주소: https://blackbold-the-company.github.io/mallang-privacy/
- 이 저장소에는 **개인정보처리방침 페이지 한 장만** 들어 있습니다.
- 검색 결과 노출을 막기 위해 `noindex, nofollow` 메타를 적용하며, 스토어 심사자가
  직접 열 수 있도록 페이지 자체는 공개 상태를 유지합니다.
- 원본 관리: 비공개 레포 `malang`의 `docs/launch/privacy/index.html`
  → 문안을 고칠 때는 **원본을 고치고 이 저장소에 복사**합니다.

## 변경 시 주의

앱이 서버 통신을 시작하면(리더보드·푸시 등) 「서버로 전송하지 않습니다」 문장이
사실과 달라집니다. 해당 기능을 붙이는 PR에서 이 문서도 함께 고쳐야 합니다.

현재 배포 대상 앱에는 실제 광고 네트워크 SDK가 없습니다. 향후 광고·분석 SDK를
추가하면 공개 전에 원본 문안과 양대 스토어의 데이터 신고를 함께 갱신합니다.
